# Sora Living

Sora Living нь Японы Йокохама, Кавасаки орчмын түрээсийн байр хайх жижиг веб апп юм. Нүүр хуудасны хайлт, байрны дэлгэрэнгүй, дуртай байр, холбоо барих форм болон админы байр/хүсэлт удирдлагатай.

## XAMPP дээр ажиллуулах

1. Apache болон MySQL-ийг асаана.
2. `http://localhost/phpmyadmin` нээгээд `databases/sora.sql` файлыг нэг удаа импортлоно. Энэ SQL нь жишээ байрнууд болон хоосон хэрэглэгчийн хүснэгт үүсгэнэ.
3. `db.php` дахь MySQL холболтын тохиргоо таны орчинтой таарч байгаа эсэхийг шалгана. XAMPP-ийн анхдагч тохиргоонд хэрэглэгч `root`, нууц үг хоосон байдаг.
4. Админ хэрэглэгчийг PHP-ээр нууц үгийн hash үүсгээд нэмнэ:

   ```sh
   php -r "echo password_hash('ӨӨРИЙН_НУУЦ_ҮГ', PASSWORD_DEFAULT), PHP_EOL;"
   ```

   Гарсан hash-ийг `users.password_hash` талбарт хадгалж, `username`-д нэвтрэх нэрээ оруулна. Жишээ SQL:

   ```sql
   INSERT INTO users (username, password_hash) VALUES ('admin', 'ЭНД_HASH_ОРОХ');
   ```

5. `http://localhost/sorafudosan/` нээгээд сайтыг ашиглана. Админ хэсэг: `login.php`.

Хуучин `sora` өгөгдлийн сантай бол эхлээд `databases/upgrade_accounts_and_preferences.sql` файлыг нэг удаа, дараа нь `databases/sample_properties.sql` файлыг phpMyAdmin-д импортлоно. Шинэчлэлтэд хэрэглэгчийн бүртгэлд зориулсан хүснэгт, тэжээвэр амьтны нөхцөл, байрны өрөөний төрөл, 28 зохиомол байр, Unsplash-аас авсан таван байрны зураг орсон. Жишээ байрны SQL-ийг дахин импортлоход ижил нэртэй байр давхар нэмэгдэхгүй.

Энгийн хэрэглэгч `register.php`-ээр бүртгүүлж, `member-login.php`-ээр нэвтэрнэ. `login.php` нь админы нэвтрэх хуудас хэвээр. Байрны хайлт болон админы байр засах хэсэгт `ペット可/不可` болон `1R`-ээс `3LDK` хүртэлх өрөөний сонголт бий.

Жишээ байрны нэр, түрээс, тайлбарууд нь зөвхөн туршилтын зориулалттай зохиомол өгөгдөл. Сайт дээр "架空のサンプル" гэж тэмдэглэгдэнэ. Эдгээрийг бодит байрны санал гэж үзэж болохгүй.

Хайлтын жишээ байршилд Йокохамагийн дүүргүүд, Кавасакигийн дүүргүүд, мөн Камакура, Фүжисава, Зүши, Ёкосүка, Ямато, Матчида, Токио хотын Ота болон Шинагава орно. Сургууль, өртөөний хайлтад Йокохама/Кавасаки орчмын нэрс нэмэгдсэн.

Админд байрны зураг анх оруулахад `images/uploads/` хавтас автоматаар үүснэ. PHP-д энэ хавтас үүсгэж, зураг хадгалах зөвшөөрөл шаардлагатай.

## Сургуулийн хайлтын утгууд

`properties.school` талбарт `yokohama`, `kanagawa`, эсвэл `令和日本語学院` утгын аль нэгийг хадгална. Эхний хоёр нь бүсийн ангилал.
